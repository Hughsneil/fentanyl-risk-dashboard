# Fentanyl-Related Accidental Death Risk Dashboard

This project is a Streamlit-based dashboard for exploring fentanyl-related accidental death records and demonstrating a machine learning binary classification model. The application provides interactive data visualisation, filtered analytical insights, and a prediction panel based on a trained XGBoost model.

## Project Title

**A Machine Learning Based Binary Classification and High Risk Feature Analysis for Fentanyl Related Accidental Deaths**

## Main Features

- Interactive dashboard for fentanyl-related accidental death analysis
- Year, sex, race, and death county filters
- KPI cards showing total records, fentanyl-related cases, fentanyl rate, and model ROC-AUC
- Yearly trend visualisation of fentanyl-related deaths
- Demographic analysis by age group, sex, and race
- Risk feature analysis based on drug involvement
- Prediction panel using a trained XGBoost binary classification model
